## 遥控器使用说明

### 控制模式

| 模式 | 触发条件 | 控制权归属 | 配套脚本 |
|------|---------|-----------|---------|
| 上位机控制模式 | 遥控器未开启 | 上位机 | `chassis_control.py` |
| 遥控器控制模式 | 遥控器开启，四号拨杆中间 | 遥控器 | `chassis_listener.py` |
| 上位机控制模式 | 四号拨杆下拨 | 上位机 | `chassis_control.py` |
| 动作模式 | 四号拨杆上拨 | 遥控器 | - |

### 遥控器控制模式操作

遥控器开启且四号拨杆（最右边）置于中间位置时：

- **右摇杆 前后**：控制底盘前进/后退
- **左摇杆 左右**：控制底盘左转/右转
- **第一拨杆 上中下**：控制立柱上升/静止/下降

运行 `chassis_listener.py` 可监听底盘速度反馈和按钮状态。

### 动作模式操作

遥控器开启且四号拨杆上拨时进入动作模式：

- 拨动第二、第三摇杆可触发不同的预设动作
动作名称	动作描述	CAN接口              触发条件
Lax	       左臂比爱心	can0 (左臂)        三号摇杆上拨
Rax	       右臂比爱心	can1 (右臂)        三号摇杆上拨

Rhs1	   右臂小挥手	can1 (右臂)        二号摇杆上拨
Rhs2	   右臂大挥手	can1 (右臂)        三号摇杆下拨
Rws	        右臂握手	can1 (右臂)        二号摇杆下拨


### 配套脚本使用

**chassis_control.py（上位机控制）**
```bash
python3 chassis_control.py
```
- CLI命令：1-8 控制底盘和立柱，q 退出
- ROS2话题：发布命令到 `/chassis/cmd`

**chassis_listener.py（数据监听）**
```bash
python3 chassis_listener.py
```
- 发布话题：`/stm32/chassis_data`（底盘速度）、`/stm32/channel_data`（按钮状态）

### 模式切换流程

```
遥控器未开启 → 上位机控制模式 → chassis_control.py
遥控器开启，四号拨杆中间 → 遥控器控制模式 → chassis_listener.py 监听
四号拨杆下拨 → 上位机控制模式 → chassis_control.py
四号拨杆上拨 → 动作模式 → 遥控器触发预设动作
```
