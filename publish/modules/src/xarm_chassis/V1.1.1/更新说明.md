# V1.1.1 更新说明

## 更新概述

本次更新主要针对 `chassis_listener.py` 文件进行了大幅重构，增强了操纵杆控制功能和底盘状态反馈能力。

## 详细更新内容

### 1. 新增立柱控制话题订阅

- **新增话题**：`/dual_xarm/py_motor_target`（Float64MultiArray）
- **功能**：接收立柱控制指令
- **回调函数**：`py_motor_position_callback()`
- **数据处理**：取 `data[2]` 值作为立柱控制信号
- **映射关系**：
  - `data[2] = 1` → 立柱上升（updown=2）
  - `data[2] = -1` → 立柱下降（updown=1）
  - 其他值 → 立柱静止（updown=0）

### 2. 速度映射逻辑调整

- **操纵杆轴分配变更**：
  - `joy[0]`（左右轴）→ 控制横向速度 `vx`
  - `joy[1]`（前后轴）→ 控制纵向速度 `vy`
  - 旋转速度 `vw` 固定为 0
- **速度计算**：`vx = int(x * max_speed)`，`vy = int(y * max_speed)`
- **速度限制**：`vx` 和 `vy` 限制在 `[-max_speed, max_speed]` 范围内

### 3. 新增里程计换算参数

- **STM32 协议**：固件发送的是 int16 大端有符号数，数值 = 实际值 * 1000
- **换算比例**：
  - `ODOM_LINEAR_SCALE = 1.0 / 1000.0`（米/单位）
  - `ODOM_ANGULAR_SCALE = 1.0 / 1000.0`（弧度/单位）
  - `ODOM_LINEAR_CORRECTION = 0.5`（线位移里程计实测偏大约 2 倍，需修正）

### 4. 新增双话题发布机制

- **话题 1**：`/stm32/chassis_data` - 发布 STM32 当前返回的绝对位移值
- **话题 2**：`/stm32/actual_distance` - 发布相对于启动位置的实际位移值
- **位移范围**：X/Y 轴最大可位移 37.767m（基于 int16 有符号数范围计算）

### 5. 新增累积位移计算

- **功能**：计算从起点开始的实时位移
- **状态变量**：`initial_x`, `initial_y`, `initial_w`（首次接收时的位移值）
- **实现方式**：
  1. 首次接收时记录起始值
  2. 后续用 `(当前值 - 起始值)` 计算实际位移

### 6. 新增角度翻转处理

- **问题背景**：旋转角度超过 360 度或低于 0 度时会发生翻转
- **解决方案**：通过检测相邻帧角度差值，自动处理跨越 360 度边界的情况
- **状态变量**：`last_w`（上一帧角度值），`w`（累积角度，不受 360 度翻转影响）

### 7. 发布数据格式变更

| 项目 | 旧版本 | 新版本 |
|------|--------|--------|
| 话题 | `/stm32/chassis_data` | `/stm32/chassis_data` |
| 数据类型 | Float64MultiArray | Float64MultiArray |
| data[0] | 横向速度 | 横向位移（米，向右为正） |
| data[1] | 纵向速度 | 纵向位移（米，前进为正） |
| data[2] | 角速度 | 旋转角度（度，顺时针为正） |

### 8. CAN 协议说明更新

- **CAN ID 0x051** 的数据含义从"速度"变更为"累积位移原始值"
- 接收数据使用 `int16` 大端格式解析（`>h`）
- 新增 `/stm32/actual_distance` 话题发布相对位移

### 9. 数据校验增强

- **操纵杆数据校验**：检查消息长度是否为 4，检查每个数据是否为有限浮点数
- **立柱数据校验**：检查消息长度是否 >= 3，不足时记录警告日志并跳过

## 代码结构变更

```

│   ├── 新增：里程计换算参数（ODOM_LINEAR_SCALE, ODOM_ANGULAR_SCALE, ODOM_LINEAR_CORRECTION）
│   ├── 新增：初始值记录（initial_x, initial_y, initial_w, last_w, w）
│   ├── 新增：/dual_xarm/py_motor_target 话题订阅
│   ├── 新增：updown_data 立柱状态缓存
│   └── 新增：/stm32/actual_distance 话题发布

├── py_motor_position_callback()  # 立柱控制数据处理
├── can_send_loop()          # 速度映射与 CAN 发送

```

## 兼容性说明

- **向后兼容**：`chassis_control.py` 无变更，CLI 和 ROS2 话题控制方式保持不变
- **CAN 协议**：发送帧（0x050）格式不变，接收帧（0x051）数据含义变更为累积位移
