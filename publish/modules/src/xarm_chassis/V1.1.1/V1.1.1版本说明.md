# 底盘控制系统 (Chassis Control System)

## 项目结构

```
chassis_system/
├── chassis_listener.py    # ROS2 节点：操纵杆/CAN 桥接器
├── chassis_control.py     # 双模式控制器：ROS2 + CLI
└── README.md              # 项目说明文档
```

## 功能特性

- **双模式控制**：ROS2 话题控制 + 命令行交互控制
- **操纵杆支持**：接收 `/dual_xarm/joystick` 话题实现远程控制
- **实时反馈**：通过 `/stm32/chassis_data` 和 `/stm32/actual_distance` 发布底盘状态
- **速度档位**：4 档可调速度（200/400/600/800）
- **立柱控制**：支持立柱上升/下降/停止
- **CAN 通信**：基于 SocketCAN，200Hz 发送频率
- **角度翻转处理**：自动处理旋转角度跨越 360 度边界的情况

## 依赖环境

### 软件依赖

```bash
# Python 库
pip install python-can

# ROS2 (推荐 Humble 版本)
sudo apt install ros-humble-rclpy ros-humble-std-msgs
```

### 硬件要求

- Linux 系统（支持 SocketCAN）
- CAN 适配器（已配置为 can2 接口）
- STM32 底盘控制器（CAN ID: 0x051）

### CAN 接口配置

```bash
# 启用 CAN 接口
sudo ip link set can2 up type can bitrate 500000

# 验证接口状态
ip link show can2

# 安装 can-utils（可选，用于调试）
sudo apt install can-utils
```

## CAN 协议说明

### 帧结构

| CAN ID | 方向 | 数据长度 | 用途 |
|--------|------|----------|------|
| 0x050 | 发送 | 8 字节 | 控制指令（速度 + 立柱） |
| 0x051 | 接收 | 8 字节 | 状态反馈（累积位移） |

### 数据帧格式（CAN ID 0x050）

| 字节位置 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| 0-1 | vx | int16 LE | 横向速度（左右） |
| 2-3 | vy | int16 LE | 纵向速度（前后） |
| 4-5 | vw | int16 LE | 角速度（旋转） |
| 6 | reserved | uint8 | 保留位 |
| 7 | updown | uint8 | 立柱状态（0=静止，1=下降，2=上升） |

### 数据帧格式（CAN ID 0x051）

| 字节位置 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| 0-1 | x | int16 BE | 横向累积位移（原始值，单位=实际值×1000） |
| 2-3 | y | int16 BE | 纵向累积位移（原始值，单位=实际值×1000） |
| 4-5 | z | int16 BE | 旋转角度（原始值，单位=实际值×1000，弧度） |

### 位移换算比例

| 轴 | 换算比例 | 说明 |
|----|----------|------|
| x | 1.0/1000.0 × 0.5 | 米/单位（向右为正，向左为负，含0.5倍修正） |
| y | 1.0/1000.0 × 0.5 | 米/单位（前进为正，后退为负，含0.5倍修正） |
| z | 1.0/1000.0 × 180/π | 度/单位（顺时针为正，逆时针为负） |

### 位移范围

- **X/Y 轴最大可位移**：37.767m（基于 int16 有符号数范围计算）

## 遥控器操作说明

遥控器配备多个拨杆和摇杆，用于控制底盘和立柱的不同操作模式：

### 拨杆功能

| 拨杆位置 | 名称 | 档位 | 功能说明 |
|----------|------|------|----------|
| 最左边 | 第一拨杆 | 上 | 立柱上升 |
| 最左边 | 第一拨杆 | 中 | 立柱静止 |
| 最左边 | 第一拨杆 | 下 | 立柱下降 |
| 最右边 | 第四拨杆 | 上 | 保留 |
| 最右边 | 第四拨杆 | **中** | **遥控模式**：遥控器摇杆控制底盘前后左右移动，上位机可启动 `chassis_listener.py` 监听底盘反馈数据 |
| 最右边 | 第四拨杆 | **下** | **上位机模式**：上位机同时监听底盘反馈数据并控制底盘（通过 `chassis_control.py`） |

### 摇杆功能（遥控模式下）

- **左右摇杆**：控制底盘横向移动（左右）
- **前后摇杆**：控制底盘纵向移动（前后）

## 使用方法

### 脚本功能说明

#### `chassis_listener.py` - 底盘监听节点

**功能定位**：ROS2 节点，负责操纵杆数据与 CAN 总线的桥接

**主要职责**：

1. **数据接收**：订阅 `/dual_xarm/joystick` 话题接收遥控器数据，订阅 `/dual_xarm/py_motor_target` 话题接收立柱控制指令
2. **速度映射**：将遥控器摇杆的模拟量（-1.0 ~ 1.0）映射为实际速度值（-max_speed ~ max_speed）
3. **CAN 发送**：将处理后的速度数据和立柱控制信号打包为 CAN 帧（ID: 0x050）发送到 STM32
4. **状态反馈**：从 CAN 总线接收 STM32 返回的底盘状态（ID: 0x051），解析位移数据后通过两个话题发布
   - `/stm32/chassis_data`：发布 STM32 当前返回的绝对位移值
   - `/stm32/actual_distance`：发布相对于启动位置的实际位移值
5. **角度翻转处理**：自动处理旋转角度跨越 360 度边界的情况，确保角度连续累加
6. **实时性保障**：以 200Hz 频率发送 CAN 数据，确保控制响应及时

**适用场景**：
- 遥控器第四拨杆拨到中间（遥控模式）时，启动此脚本监听底盘反馈数据
- 上位机需要获取底盘实时状态时使用

#### `chassis_control.py` - 双模式控制器

**功能定位**：底盘运动控制器，支持 ROS2 话题控制和命令行交互控制

**主要职责**：

1. **双模式支持**：优先检测 ROS2 环境，可用则启动 ROS2 节点；不可用则回退到纯 CLI 模式
2. **底盘运动控制**：支持停止、前进、后退、左转、右转等基础运动指令
3. **立柱控制**：支持立柱上升、下降、停止
4. **速度档位**：提供 4 档可调速度（200/400/600/800）
5. **CAN 发送**：将控制指令打包为 CAN 帧（ID: 0x050）发送到 STM32

**适用场景**：
- 遥控器第四拨杆拨到下面（上位机模式）时，使用此脚本控制底盘
- 需要通过 ROS2 话题或命令行手动控制底盘时使用

### 启动命令

```bash
# 启动底盘监听节点（遥控模式下监听反馈）
cd chassis_system
python3 chassis_listener.py
```

```bash
# 启动控制器（上位机模式下控制底盘，优先 ROS2）
cd chassis_system
python3 chassis_control.py
```

### ROS2 话题控制

底盘运动控制：
```bash
ros2 topic pub /chassis/cmd std_msgs/String "data: 'stop'"
ros2 topic pub /chassis/cmd std_msgs/String "data: 'forward'"
ros2 topic pub /chassis/cmd std_msgs/String "data: 'backward'"
ros2 topic pub /chassis/cmd std_msgs/String "data: 'left'"
ros2 topic pub /chassis/cmd std_msgs/String "data: 'right'"
```

立柱控制：
```bash
ros2 topic pub /chassis/cmd std_msgs/String "data: 'lift_up'"
ros2 topic pub /chassis/cmd std_msgs/String "data: 'lift_down'"
ros2 topic pub /chassis/cmd std_msgs/String "data: 'lift_stop'"
```

速度设置：
```bash
ros2 topic pub /chassis/cmd std_msgs/String "data: 'speed_1'"  # 速度 200
ros2 topic pub /chassis/cmd std_msgs/String "data: 'speed_2'"  # 速度 400
ros2 topic pub /chassis/cmd std_msgs/String "data: 'speed_3'"  # 速度 600
ros2 topic pub /chassis/cmd std_msgs/String "data: 'speed_4'"  # 速度 800
```

### 操纵杆控制（通过 chassis_listener.py）

操纵杆话题 `/dual_xarm/joystick`（Float64MultiArray，4个元素）：
- data[0]：左右轴 → 控制横向速度 vx
- data[1]：前后轴 → 控制纵向速度 vy

立柱话题 `/dual_xarm/py_motor_target`（Float64MultiArray）：
- data[2]：立柱控制 → 1=上升，-1=下降，其他=静止

### 底盘状态话题

```bash
ros2 topic echo /stm32/chassis_data
```

发布数据格式（Float64MultiArray，3个元素）：
- data[0]：横向位移（米，向右为正，STM32 绝对位移值）
- data[1]：纵向位移（米，前进为正，STM32 绝对位移值）
- data[2]：旋转角度（度，顺时针为正）

```bash
ros2 topic echo /stm32/actual_distance
```

发布数据格式（Float64MultiArray，3个元素）：
- data[0]：横向位移（米，向右为正，相对于启动位置）
- data[1]：纵向位移（米，前进为正，相对于启动位置）
- data[2]：旋转角度（度，顺时针为正，累积角度，不受 360 度翻转影响）

## 配置说明

### 主要参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| max_speed | 800 | 最大速度限制 |
| can_id | 0x050 | 发送 CAN ID |
| send_hz | 200 | CAN 发送频率 |
| channel | can2 | CAN 接口名称 |
| ODOM_LINEAR_SCALE | 1.0/1000.0 | 线位移换算比例（米/单位） |
| ODOM_ANGULAR_SCALE | 1.0/1000.0 | 角位移换算比例（弧度/单位） |
| ODOM_LINEAR_CORRECTION | 0.5 | 线位移修正系数 |

### 修改参数

在 `chassis_listener.py` 或 `chassis_control.py` 中修改对应常量即可。

## 注意事项

1. 运行前确保 CAN 接口已正确配置
2. 使用 ROS2 模式时需要先 source ROS2 环境
3. 退出程序时会自动发送停止指令，确保安全
4. 速度值范围为 -max_speed 到 max_speed
5. 立柱状态仅支持上升(2)、下降(1)、静止(0)三种状态
6. CAN ID 0x051 返回的是累积位移原始值（int16 大端），数值 = 实际值 × 1000
